# Kananelo Moloi — Portfolio (static site)

Plain HTML, CSS and JavaScript. No build step, no framework.

```
index.html   — all page content
styles.css   — design system, layout, animations
script.js    — typing roles, marquee, scroll progress, reveal-on-scroll
assets/      — chatbot screenshot + CV PDF
```

## View locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Push this folder's contents to a repository (e.g. `kananelo-portfolio`).
2. Repo → **Settings → Pages**.
3. Source: **Deploy from a branch**, branch `main`, folder `/ (root)` if these files are at the repo root, or `/docs` if you kept them in this `docs` folder.
4. Save — the site goes live at `https://<username>.github.io/<repo>/`.
